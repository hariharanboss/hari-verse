# Hari-Verse 🚀

My personal portfolio and ecosystem showcase — a modern, animated web experience built with **Next.js 15**, **React 19**, **Tailwind CSS 4**, and **Framer Motion**.

🌐 **Live demo:** [hari-verse-plum.vercel.app](https://hari-verse-plum.vercel.app)

## ✨ Features

- **Personal portfolio** to showcase projects, skills, and experience
- **Smooth animations & transitions** powered by Framer Motion
- **Modern, responsive UI** styled with Tailwind CSS 4
- **App Router** architecture with Next.js 15
- **Optimized production builds** with static optimization where possible
- **Deployed on Vercel** for fast, global delivery

## 📦 Getting Started

### Prerequisites

- **Node.js** (v18.18+ or v20+ recommended for Next.js 15)
- **npm**

### Installation

```bash
# Clone the repository
git clone https://github.com/hariharanboss/hari-verse.git
cd hari-verse

# Install dependencies
npm install
```

### Running Locally

```bash
# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build & Run Production

```bash
# Create an optimized production build
npm run build

# Run the production server locally
npm start
```

## 🌍 Deployment (Vercel)

This project is ready for Vercel deployment:

1. Push the repository to GitHub.
2. Import the repository in [Vercel](https://vercel.com).
3. Keep the default **Next.js** framework preset.
4. Use `main` as the production branch.
5. Add environment variables in Vercel if the project needs them.
